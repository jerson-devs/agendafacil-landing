# Aprendiendo Git & Github
- Estos son los paros para iniciar con Git
## Paso 1
- Inicializar el nuevo repositorio
```
git init
```
- Directorio de Trabajo donde se escribe el código
## Paso 2
- Enviar los nuevos archivos o archivos modificados al area de preparación
```
git add index.html
git add
```
- El Área de preparación es donde se preparan los cambios

## Paso 3
- Registrar una descripción del cambio realizado
```
git commit -m "proyecto base"
```


# Github

```
git remote add origin https://github.com/jerson-devs/agendafacil-landing.git
```

- Enviar los cambios al repositorio remoto
```
git push origin master
```
